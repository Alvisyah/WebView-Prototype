# Siklus 1: Prototype Awal (MIT App Inventor)

Prototype aplikasi WebView yang dibuat di [MIT App Inventor](https://appinventor.mit.edu) sebagai Tugas Sesi #2 mata kuliah Pemrograman Mobile. Prototype ini menjadi siklus pertama metode prototyping, lalu diperbaiki pada siklus kedua dengan React Native (lihat folder `siklus-2-react-native`).

## Ringkasan

- Dibuat dengan komponen `WebViewer` dan pemrograman berbasis blok.
- Tujuan: memastikan ide menampilkan halaman web di dalam aplikasi mobile berjalan.
- Hasil: aplikasi dapat memuat halaman web di dalam aplikasi.

## Keterbatasan yang Diperbaiki di Siklus 2

- Kontrol terhadap kode dan perilaku aplikasi terbatas.
- Sulit menambahkan pustaka pihak ketiga atau fitur kustom.
- Tidak dapat dikelola dengan alur kerja pengembang umum (editor kode, Git, npm).
